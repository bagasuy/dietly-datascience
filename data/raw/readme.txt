DietDiary Dataset
=================

Dataset:
DietDiary — Navigating Weight Prediction with Diet Diary

Description:
The DietDiary dataset contains weight measurements of real users and
their food intake records, including images and ingredient annotations.

The original dataset package contains:

- data.csv
  Records including user ID, recording date, image path, ingredient
  annotations of three meals, and weight measurements (kg).

- DietDiary.zip
  Images of food intake.

- predict_ingr.json
  Ingredient prediction results from FoodLMM for the food images.

This Dietly repository uses:

- data.csv

The original image archive (DietDiary.zip) and ingredient prediction
file (predict_ingr.json) are not included in this repository.

Original source:
https://github.com/yxG1005/Weight_Prediction

The original repository provides the dataset through an external
Google Drive download.
